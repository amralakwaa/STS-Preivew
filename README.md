# STS Glass

Next.js (React 19) + Tailwind + Framer Motion rebuild of the STS Smart Tech Systems website with a liquid-glass design.

- Arabic (RTL) and English
- Real lens refraction via an SVG displacement backdrop-filter (Chromium; other browsers fall back to frosted glass)
- Pointer-tracked specular rims, 3D tilt, parallax, scroll reveals

```bash
npm install
npm run dev
```
